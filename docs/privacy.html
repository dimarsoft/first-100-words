Политика конфиденциальности

Приложение «Первые 100 слов» (First100Words). Действует с 26 ноября 2026 года. English version

«Первые 100 слов» — бесплатное приложение-дневник, в котором родители записывают первые слова ребёнка. Мы не собираем, не храним и не передаём ваши данные. Ниже описано, где они находятся и кто к ним имеет доступ.

Какие данные вводятся в приложение

  • Имя ребёнка (необязательно) и дата рождения — чтобы считать возраст.
  • Слова: как ребёнок их произносит, что они значат, дата появления, рассказ «Как появилось слово?».
  • Аудиозаписи, если вы их сделаете (до 60 секунд на слово).

Где хранятся данные

  • На вашем телефоне. Всё хранится в памяти браузера на устройстве. У приложения нет сервера: данные никуда не отправляются, и разработчик их не видит.
  • В файлах, которые вы сохраняете сами. Резервная копия, таблица CSV и печать создаются только по вашей команде, и вы сами решаете, куда их отправить (Telegram, почта, файлы телефона и т. д.).
  • В вашем Google Диске — только если вы нажмёте «Сохранить на Google Диск».

Google Диск

  • Вход выполняется через Google. Приложение запрашивает только доступ drive.file: это значит, что оно видит лишь файлы, которые создало само. Остальное содержимое вашего Диска ему недоступно.
  • На Диске создаётся один файл «Первые 100 слов — копия.json» с вашими словами, данными ребёнка и аудиозаписями. Он лежит в вашем аккаунте; разработчик доступа к нему не имеет.
  • Данные передаются напрямую между вашим телефоном и Google, без промежуточных серверов.
  • Временный ключ доступа от Google хранится только в памяти открытой страницы и не сохраняется.
  • Данные, полученные от Google, используются только для сохранения и загрузки этой копии и никому не передаются. Использование соответствует политике Google API Services User Data Policy, включая требования об ограниченном использовании (Limited Use).
  • Отключить доступ можно в приложении («Настройки → Отключить Google Диск») или в настройках аккаунта Google. Файл копии можно удалить с Диска в любой момент.

Чего в приложении нет

  • Регистрации и аккаунтов приложения.
  • Рекламы, аналитики, счётчиков посещений и файлов cookie для отслеживания.
  • Передачи данных третьим лицам.

Микрофон

Микрофон используется только когда вы сами нажимаете запись аудио или диктовку. Запись сохраняется на телефоне. Диктовка текста выполняется средствами браузера или клавиатуры телефона по их собственным правилам.

Удаление данных

Чтобы удалить всё, очистите данные сайта в настройках браузера или удалите приложение с главного экрана вместе с данными. Копию на Google Диске и сохранённые файлы удалите там, где они лежат.

Изменения и контакты

Если политика изменится, новая версия появится на этой странице. Вопросы можно задать через страницу проекта на GitHub.

Privacy Policy

First100Words («Первые 100 слов»). Effective date: November 26, 2026.

First100Words is a free diary app in which parents record their child's first words. The app is developed by an individual developer, has no server and does not collect, store or share user data. This policy explains what data the app handles, where it is kept and how Google user data is used.

Data the user enters

  • The child's name (optional) and date of birth — used only to show the child's age.
  • Words: the child's pronunciation, meaning, date, whether the child said it independently, and an optional note.
  • Optional audio recordings (up to 60 seconds per word), made only when the user taps the record button.

Where data is stored

  • On the user's device, in the browser's local storage (IndexedDB). Nothing is sent to the developer; the developer has no access to it.
  • In files the user exports (backup, CSV table, print/PDF), only when the user chooses to, to a destination the user selects.
  • In the user's own Google Drive, only if the user taps “Save to Google Drive”.

Google user data

Data accessed

The app requests a single OAuth scope: https://www.googleapis.com/auth/drive.file. With it the app can create, read, update and delete only the files it created itself. It cannot see, read or modify any other files in the user's Google Drive. The app does not request the user's name, email address, contacts or any other Google data.

How the data is used

The app creates one file named “Первые 100 слов — копия.json” in the user's Drive containing a backup of the diary (words, the child's name and date of birth, audio recordings). It is used only to save this backup when the user taps “Save to Google Drive” and to restore it when the user taps “Load from Google Drive” (for example, on a new phone). Google data is not used for any other purpose, including advertising, analytics, profiling or training AI/ML models.

Sharing

Google user data is not shared with, transferred to or sold to anyone. Data travels directly between the user's device and Google over HTTPS; there are no intermediate servers.

Storage and protection

The backup file is stored only in the user's Google Drive account. The temporary access token issued by Google is kept only in the memory of the open page (about one hour) and is never written to storage or sent anywhere except to Google APIs.

Retention and deletion

The backup file remains in the user's Drive until the user deletes it. The user can revoke the app's access at any time in the app (“Settings → Disconnect Google Drive”) or at myaccount.google.com/permissions, and can delete the backup file from Google Drive. Data on the device is deleted by clearing the site data in the browser or by uninstalling the app.

Limited Use

First100Words' use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

What the app does not do

  • No accounts, no ads, no analytics or tracking cookies, no third-party SDKs other than Google Sign-In.
  • No AI features; the app does not create or process images.

Microphone

The microphone is used only while the user records audio or dictates text. Recordings are stored on the device.

Children

The app is intended for parents. It does not collect any data from children; information about the child is entered by the parent and stays on the parent's device or in the parent's own Google Drive.

Changes and contact

Updates to this policy will be published on this page. Questions can be asked via the project page on GitHub.
