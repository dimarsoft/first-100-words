# «Первые 100 слов» — требования (версия 1)

Обновлено: 24 ноября 2026. Основа — `pervye_100_slov_dialog.md` и последующее обсуждение.

## Формат
- PWA (сайт-приложение): ставится на главный экран Android, работает без интернета.
- Данные хранятся на телефоне (IndexedDB). Резервная копия — файлом через «Поделиться»
  (Telegram / Google Диск / почта), восстановление из файла на новом телефоне.
- Google Диск: кнопки «Сохранить на Google Диск» / «Загрузить с Google Диска» в настройках
  и «Загрузить с Google Диска» на первом запуске. Один файл `Первые 100 слов — копия.json`
  (тот же формат, что у резервной копии, перезаписывается). Доступ `drive.file` — приложение
  видит только свой файл. Загрузка заменяет данные на телефоне после подтверждения.
  Сохранение на Диск считается резервной копией (сбрасывает напоминание).
- Напоминание о резервной копии: если есть новые слова и с прошлой копии прошло 14 дней.
- Схема данных версионируется — новые поля (например, «дата последнего подтверждения»)
  добавляются позже без потери данных.

## Ребёнок
- При первом запуске: имя (необязательно) и дата рождения (для расчёта возраста).
- Один ребёнок в версии 1.

## Слово (единица учёта: «детское произношение → значение»)
| Поле | Правила |
|---|---|
| Как сказал(а) | Обязательно. Вводится обычными буквами. |
| Ударение | Нажатием на гласную в крупных плитках. Одна гласная — ставится автоматически. Многосложное слово без ударения сохранить нельзя. Если мама сама набрала ударную гласную заглавной — это принимается как выбор ударения. Ударная гласная показывается заглавной. Это фактическое ударение ребёнка. |
| Значение | Обязательно. Подсказки: список типичных первых слов + уже введённые значения. |
| Дата появления | По умолчанию сегодня; кнопки «Сегодня», «Вчера», календарь. Будущая дата и дата раньше рождения недопустимы. При редактировании дата не меняется. |
| Сам / повторил | Переключатель, по умолчанию «сам». Оба варианта входят в 100, в статистике — раздельно. |
| Как появилось слово? | Необязательно (это и есть комментарий, отдельного поля нет). Можно надиктовать микрофоном (клавиатура или кнопка 🎤 в приложении) — сохраняется текстом. |
| Аудио | Необязательно. До 60 секунд, авто-стоп на 60 с, можно остановить раньше, прослушать, перезаписать, удалить. |

- Одинаковое произношение с разными значениями — разные слова («кА» = каша, «кА» = кошка).
- Повтор пары «произношение + значение» — предупреждение «уже есть».
- То же значение с новым произношением — предложение «обновить произношение»;
  старое (с аудио) уходит в историю слова, новое слово не создаётся.
- Черновик («Дополнить позже»): достаточно произношения; в счёт 100 не идёт, пока не дополнен.

## Экраны
- **Список:** счётчик N/100, полоса прогресса, поиск (по произношению и значению),
  черновики сверху. Строка: №, произношение, значение, дата «12 нояб»
  (год добавляется, только если он не текущий), значки 🔊 (аудио) и 📝 (есть «Как появилось»).
  Возраст ребёнка указывается в строке первого слова.
- **Карточка слова:** вся информация, полная дата, возраст ребёнка на момент слова
  в формате «N лет, N месяцев, N дней» (включая нулевые значения),
  аудио, история произношения, редактирование, удаление.
- **Статистика:** первое слово, сам/повтор, даты достижения 10/30/50/80/100 слов с возрастом,
  слова по месяцам.
- **Настройки:** данные ребёнка, резервная копия, восстановление, таблица для специалиста; версия приложения, короткий хеш и дата коммита
  (CSV для Excel и печать/PDF; столбец «Аудиозапись» — есть/нет; крайний правый столбец — «Как появилось слово?»).

## Поздравления
- На 10, 30, 50, 80, 100 словах. Каждое — один раз.

## Отложено (на следующие версии)
- Дата последнего подтверждения («Снова сказал(а)»).
- Несколько детей.
- Нейтральная отметка «ударение неясно» (пока — строгое правило).
